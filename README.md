# Fundi Karibu

Find a mechanic ("fundi") near you when your car breaks down on Kenyan roads.

## Features

- **Find a fundi**: pick your nearest town or Nairobi area and the problem, and see mechanics sorted by distance.
- **Mechanics board**: live Available / Busy / Offline status for every listed mechanic.
- **Help requests**: drivers post a request, mechanics nearby take the job.
- **Consultation fee**: M-Pesa Till or Paybill card with confirmation-code entry, checked by an admin.
- **Mechanic listing**: garages list services, vehicle types, hours and call-out range.
- **Fundi AI**: roadside troubleshooting chat (works only when the app runs inside Claude).

## Demo mode

Opened outside Claude (for example on GitHub Pages), the app runs in **demo mode**:
example mechanics, data saved only in your browser, and calling and WhatsApp switched off.
Use **Reset demo** in the yellow bar to start over.

## Run it

It's a single file with no build step. Open `index.html` in a browser, or publish it with GitHub Pages.
